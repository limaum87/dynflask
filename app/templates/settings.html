{# Quick guide #}

Como obter as credenciais

1

Zone ID

No painel do Cloudflare, acesse seu domínio. O Zone ID aparece na página Overview, na barra lateral direita.

2

API Token

Acesse API Tokens, crie um token com o template Edit zone DNS e selecione sua zona.

{# API Usage #}

Exemplo de uso da API

curl -X POST \
  http://localhost:5000/update \
  -H "Content-Type: application/json" \
  -d '{
    "hostname": "home.domain.com",
    "token": "seu_token"
  }'

Se ip não for enviado, o IP de origem da requisição será usado automaticamente.

{# Quick guide — Cloudflare #}

Cloudflare — Credenciais

1

Zone ID — No painel do Cloudflare, acesse seu domínio → Overview → barra lateral direita.

2

API Token — Acesse API Tokens, crie com o template Edit zone DNS.

{# Quick guide — Route53 #}

Route53 — Credenciais

1

Hosted Zone ID — Console AWS → Route53 → Hosted zones → selecione sua zona.

2

Access Key — Console AWS → IAM → Users → Create User → Create Access Key.

3
IAM Policy mínima: 
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "route53:ChangeResourceRecordSets",
      "route53:ListResourceRecordSets",
      "route53:GetHostedZone"
    ],
    "Resource": "arn:aws:route53:::hostedzone/ZONE_ID"
  }]
}
{# API Usage #}

Exemplo de uso da API

curl -X POST \
  http://localhost:5000/update \
  -H "Content-Type: application/json" \
  -d '{
    "hostname": "home.domain.com",
    "token": "seu_token"
  }'

O provider é definido por host ao cadastrar. A API usa automaticamente o provider correto.
